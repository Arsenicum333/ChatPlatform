Chat platform that you never asked, but always wanted

# Project Setup [For Dev]

## Prerequisites
- Node.js (v18+)

## Setup & Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start Dev Server:**
   ```bash
   npm run dev
   # or
   quasar dev
   ```

## Build
```bash
npm run build
```
